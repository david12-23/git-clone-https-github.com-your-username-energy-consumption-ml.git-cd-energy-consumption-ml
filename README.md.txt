# Energy Consumption Optimization

Machine Learning project that predicts and optimizes energy consumption using data analysis and predictive modeling techniques.

## Features

- Energy consumption prediction
- Data preprocessing
- Predictive analytics
- Flask web application
- Energy efficiency optimization

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Flask
- Matplotlib

## Run Application

```bash
python app.py
```

Open browser:

```text
http://127.0.0.1:5000
```
